# Harman Sweets

Luxury Next.js website for Harman Sweets, Dhuri. The palette uses wine, antique gold, cream, and cocoa for an attractive premium Indian sweets aesthetic.

Run locally with `npm install && npm run dev`.

Deploy to Netlify: import this GitHub repository, use build command `npm run build`, and publish directory `.next`.
